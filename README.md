# AI支援工房｜ロボット・FAとAIアプリ開発

ロボット・FAの上流エンジニアとして、自動化の企画・構想、機構の3D CAD設計、ロボットのプログラミングに携わってきました。ロボットシミュレーターに携わった経験は20年です。

SIerを経営していたときには、オリジナルの搬送ロボットを自ら3D CADで設計し、製作から納品まで担当しました。メーカーの技術アドバイザーも経験しています。

現在は、ロボットシミュレーターのほか、AIを使った業務向けWebアプリや画像処理ツールを開発しています。

## ロボットシミュレーション

**R-SIM｜メカ設計とロボットの干渉確認に使えるシミュレーター**  
R-SIMは、FreeCADを土台に、メカ・治具の設計とロボットの干渉確認に使える状態です。ロボットや周辺設備の配置、姿勢、通過範囲を見比べながら設計を検討できます。AIがモデル作成や変更をアシストし、中小の製造機器SIerの導入費用と設計工数を抑えることを目指しています。  
https://bizai-evo.com/cad-robot/r-sim/

**MLR-SIM｜AI支援でLadder回路の作成を早める**  
機構モデル、仮想PLC、自作の操作パネル「VCP」をつなぐ設備シミュレーターを開発しています。日本語ラダー／STエディター「PLCedi」も自作しています。AIで設備仕様の整理や回路の下書きを支援し、ラダー回路の作成と見直しにかかる工数を減らすことが目的です。  
https://bizai-evo.com/pdf/MLR-SIM_Mechanical&ControlCircuitSimulation.pdf

**AR-SIM｜フィジカルAIの研究と将来の実装**  
自律ロボットが周囲を観測し、その情報を動作にどうつなげるかを研究しています。FreeCADとBlenderを使い、機体と作業環境を一緒に検討できるシミュレーション環境を開発しています。将来、研究した手法をロボットに実装して検証することを目指しています。  
https://bizai-evo.com/pdf/AR-SIM__Autonomous_Robot_Simulation_PR_261103.pdf

## AIアプリ

- **Audit2Build** — SEO・GEO・AIOの観点からWebページを診断し、改善案を出すWebアプリ。
- **QGA Scaler** — 複数の超解像モデルで画像を拡大し、元画像と並べて比較できるWindowsアプリ。
